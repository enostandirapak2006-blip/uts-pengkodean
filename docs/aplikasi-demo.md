# Aplikasi demonstrasi privat

URL: https://enos-uts-voucher-kas.prettygoby64.chatgpt.site

Aplikasi hasil build frontend-canvas dipublikasikan secara privat untuk pemilik. Backend tetap memakai proyek Supabase uts-pengkodean yang sama. Publishable key dikonfigurasi pada deployment sebagai konfigurasi publik; secret/service_role key tidak digunakan. Login aplikasi menggunakan pengguna Supabase Auth dengan email dan password khusus aplikasi, bukan login pemilik dashboard.

Pengguna aplikasi untuk email yang dipilih sudah ditemukan dan terkonfirmasi. Deployment berhasil. Pengujian browser/login dan submit end-to-end masih menunggu hasil pengguna; keberhasilan deployment tidak membuktikan seluruh alur login sudah lulus.

Voucher uji yang disarankan: nomor bukti UTS-TEST-001, deskripsi Uji login dan posting, Debit Beban Operasional 50000, Kredit Bank 50000. Form menampilkan total Rp50.000,00. Pilih Submit lalu periksa pesan sukses. Password dan token login tidak dicatat dalam screenshot atau dokumentasi.

Situs privat merupakan sarana demonstrasi. Untuk penilaian dosen, repo GitHub publik dan PDF adalah sumber artefak utama; akses privat ini tidak dianggap bisa dibuka dosen tanpa perubahan audience yang disetujui pengguna.
