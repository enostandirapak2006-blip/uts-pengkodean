===== docs/soal-3.md =====
# Jawaban Soal 3

## 3.1 Form kas keluar dan orkestrasi AI

Prototipe frontend React terdapat pada frontend/. Form memuat tanggal, nomor bukti, deskripsi, dan baris akun yang dapat ditambah/dihapus. Total debit/kredit dihitung langsung; Submit hanya aktif jika minimal dua baris, nominal valid, total debit = kredit > 0, satu akun kas/bank di kredit dan akun lawan di debit. Nominal frontend dihitung dalam sen menggunakan BigInt untuk menghindari selisih floating point. Database memakai NUMERIC dan tetap memvalidasi semua input, sehingga bypass frontend tidak menghilangkan pemeriksaan.

Pengguna telah membuat rancangan melalui Gemini Canvas menggunakan prompt aktual pada docs/prompt-ai.md. Output TSX dan screenshot disimpan pada evidence/gemini/. Form utama hasil Canvas dan perbaikan integrasinya berada pada frontend-canvas/; detail temuan serta perubahan pada docs/gemini-review.md. Frontend sederhana pada frontend/ dibuat dalam sesi coding ini untuk pemeriksaan audit dan pembalik. NotebookLM belum dijalankan sehingga ringkasan verifikasi akuntansi belum tersedia.

## 3.2 Backend dan pengendalian audit

SQL lengkap pada sql/04_cash_backend.sql. Supabase RPC submit_cash_voucher menerima tanggal, nomor bukti, deskripsi dan array baris. Fungsi SECURITY INVOKER memeriksa auth.uid(), memvalidasi input, membuat header DRAFT, menambahkan baris, lalu melakukan posting. Semua langkah dalam satu transaksi; kegagalan membatalkan keseluruhan voucher. RLS membatasi akses jurnal pada pembuatnya. Akun master dapat dibaca pengguna login tetapi tidak diubah lewat frontend. Pengguna anonim tidak diberi akses jurnal maupun RPC.

Trigger database menolak UPDATE/DELETE header POSTED dan perubahan barisnya. RLS juga membatasi update/delete pada DRAFT; pada API pengguna, upaya perubahan POSTED dapat menghasilkan nol baris terpengaruh. Aplikasi tidak boleh menafsirkannya sebagai perubahan berhasil. Koreksi dilakukan lewat reverse_journal: membuat header baru dengan reversal_of mengacu jurnal asli, menukar debit/kredit seluruh baris, lalu memposting jurnal baru. UNIQUE pada reversal_of mencegah dua pembalik langsung untuk jurnal asal yang sama.

created_by diisi dari identitas login yang diverifikasi Supabase Auth, bukan ID yang dikirim klien. created_at ditetapkan oleh database dan kedua field tidak dapat diubah. Audit AFTER trigger mencatat INSERT/UPDATE/DELETE header dan baris dengan actor_id, waktu, data lama serta data baru. Audit log append-only untuk role aplikasi; perubahan log juga ditolak trigger. Aksi SQL administratif dapat memiliki actor_id NULL, sehingga tetap perlu log administrasi eksternal.

Audit trigger SECURITY DEFINER diperlukan khusus agar log bisa ditulis meski klien hanya punya akses baca. Fungsi itu berada di schema private, mempunyai search_path kosong dan hak EXECUTE langsung dicabut. RPC bisnis tetap SECURITY INVOKER dan mengikuti RLS. Fungsi checksum private mendapat izin execute untuk role authenticated, tetapi pembacaan baris tetap mengikuti RLS.

hash_checksum menggunakan SHA-256 atas JSONB dengan versi format, atribut header serta baris yang diurutkan berdasarkan id. created_at direpresentasikan sebagai epoch supaya timezone sesi tidak mengubah digest. Hash dihitung saat posting dan verify_journal menghitung ulang untuk membandingkan. Digest membantu mendeteksi perubahan isi setelah posting; bukan tanda tangan digital atau perlindungan terhadap administrator yang dapat mengubah isi dan hash sekaligus. Perubahan master akun tidak tercakup dalam digest, sehingga master akun juga harus dikendalikan dan diaudit pada sistem produksi.

## Cara menjalankan prototipe

Form utama Canvas: jalankan `npm ci`, `npm run build`, lalu `npm run preview` dari root repo. Buka http://localhost:8000. React/React DOM dipatok 19.2.0, lucide-react 1.55.0, Tailwind CSS 3.4.17, dan esbuild 0.28.2; package-lock.json mencatat resolusi dependensi. Bundle hasil build tidak memerlukan CDN untuk React.

Frontend pemeriksaan audit: jalankan `python3 -m http.server 8001 --directory frontend`, lalu buka http://localhost:8001. Frontend ini memakai CDN React/React DOM 19.2.0 dan membutuhkan internet.

Di Supabase Dashboard, buat pengguna aplikasi lewat Authentication > Users. Akun dashboard Supabase tidak otomatis menjadi pengguna aplikasi. Ambil Publishable key proyek melalui pengaturan API, kemudian masukkan pada form login bersama email/password pengguna aplikasi. Jangan memakai secret/service_role key. Key dan access token hanya disimpan pada state memori halaman. Prototipe tidak melakukan refresh session otomatis; bila token kedaluwarsa, keluar lalu login ulang. Gunakan HTTPS saat dihosting selain localhost.

Daftar akun awal telah disediakan, termasuk Kas, Bank, Persediaan, Utang, HPP, dan Beban Operasional. Penandaan is_cash dikendalikan administrator. Klasifikasi kas/setara kas harus ditinjau terhadap sumber akuntansi melalui NotebookLM sebelum penggunaan final. Prototipe kas keluar tidak mencakup transfer antarkas, valuta asing, pajak, approval berjenjang, atau periode tutup buku.

## Batas verifikasi saat ini

Backend diuji pada PostgreSQL Supabase 17.11 menggunakan role authenticated dan klaim identitas uji melalui SQL administratif, bukan token login pengguna nyata. Browser frontend dan alur login end-to-end belum diuji. Advisor terakhir tidak melaporkan warning fungsi; dua info RLS tanpa policy pada tabel stok disengaja karena tabel itu hanya digunakan melalui SQL administratif pada tahap ini. Detail hasil ada pada docs/hasil-pengujian.md.

# Tinjauan dan perbaikan kode Gemini Canvas

Pengguna memberikan prompt aktual, kode prototipe_voucher_kas_keluar.tsx, dan tiga screenshot hasil Canvas. Kode original disimpan tanpa perubahan pada evidence/gemini/original.tsx; versi hasil tinjauan pada frontend-canvas/CashVoucherApp.tsx. Tampilan hijau, tabel baris dinamis, ikon, indikator balance dan penjelasan UI dipertahankan dari hasil Gemini.

| Temuan pada kode asli | Perbaikan |
| --- | --- |
| parseToCents menganggap digit input sebagai sen, tetapi kolom berlabel Rp; 5000000 dikirim sebagai 50000.00 | Rupiah dibaca sebagai string desimal kemudian dikalikan 100 menggunakan BigInt; payload 5000000.00 |
| Parser membuang semua karakter nondigit sehingga -100 menjadi 100 dan format desimal dapat berubah makna | Parser ketat menolak negatif, teks, pemisah ribuan, dan lebih dari dua desimal |
| Number/parseInt dapat kehilangan presisi untuk nominal besar | BigInt dan konversi payload string tanpa pembagian floating point |
| account_id berupa acc_kas/acc_bank dan ID contoh lain, sedangkan backend memakai BIGINT | Akun dimuat dari chart_of_accounts setelah login dan ID dikirim sebagai string ID aktual |
| Authorization menggunakan anon key sebagai Bearer; tidak ada login pengguna | Login Supabase Auth, apikey memakai publishable key, Bearer memakai access_token pengguna; sesi hanya di memori |
| Pemeriksaan hanya menghitung kas di kredit dan memastikan ada satu lawan debit, tanpa melarang kas tambahan debit/lawan tambahan kredit | Seluruh baris diperiksa; tepat satu kas kredit dan seluruh akun nonkas debit |
| Tidak ada validasi metadata dalam logika tombol Submit | Tanggal, nomor bukti, deskripsi dan batas 50 karakter referensi diperiksa |
| Jumlah baris tanpa batas dan ID baris dari Date.now() | Maksimal 100 baris sesuai RPC dan UUID untuk baris tambahan |
| Tanggal awal memakai UTC | Tanggal awal memakai zona Asia/Jakarta |

Script tests/canvas.test.mjs memeriksa konversi Rp5.000.000, string payload, presisi desimal, input tidak valid, keseimbangan, metadata kosong, akun tidak dikenal, serta tambahan kas debit/lawan kredit. Uji ini lulus. Build esbuild/Tailwind berhasil menghasilkan bundle React dan CSS. Pengujian browser/login belum dilakukan; lolos build tidak membuktikan login dan penyimpanan cloud berhasil.

Frontend Canvas yang diperbaiki menjadi form utama hasil orkestrasi Gemini. Frontend sederhana pada frontend/ tetap tersedia sebagai alat pemeriksaan audit log, checksum dan jurnal pembalik; backend RPC keduanya sama. Pemisahan ini dicatat agar fitur audit yang dibuat dalam sesi coding tidak keliru diklaim sebagai output Gemini.

Konfigurasi login: pengguna Supabase Auth aplikasi harus dibuat dahulu. Pemeriksaan auth.users saat tinjauan menunjukkan belum ada pengguna aplikasi. Akun pemilik dashboard tidak otomatis menjadi akun aplikasi. Jangan memakai password utama Google sebagai password demonstrasi aplikasi atau mengunggah kredensial ke repo.


===== frontend-canvas/CashVoucherApp.tsx =====
import React, { useState, useEffect, useMemo } from 'react';
import { 
  Plus, Trash2, CheckCircle2, AlertCircle, FileText, 
  Calendar, Hash, FileEdit, ShieldCheck, Database, Info, RefreshCw
} from 'lucide-react';

import {parseToCents,formatIDR,decimalString,journalTotals,validateVoucher} from './canvas-model.mjs';

export default function App() {
  const [date, setDate] = useState(new Date().toLocaleDateString('en-CA', {timeZone:'Asia/Jakarta'}));
  const [reference, setReference] = useState('VKK-2026-001');
  const [description, setDescription] = useState('Pembayaran beban operasional bulan ini');
  
  /* Initial 2 rows for Kas Keluar (e.g., Expense Debit, Bank Credit) */
  const [lines, setLines] = useState([
    { id: 1, account_id: '', debit: '5000000', credit: '0' },
    { id: 2, account_id: '', debit: '0', credit: '5000000' }
  ]);

  /* Supabase Connection Config State */
  const supabaseUrl = 'https://gkcklzfvwwvzfxcrgmav.supabase.co';
  const [supabaseAnonKey, setSupabaseAnonKey] = useState('');
  const [isSubmitting, setIsSubmitting] = useState(false);
  const [submitResult, setSubmitResult] = useState(null);
  const [showConfig, setShowConfig] = useState(true);
  const [MASTER_ACCOUNTS, setAccounts] = useState([]);
  const KAS_BANK_IDS = MASTER_ACCOUNTS.filter(a => a.is_cash).map(a => a.id);
  const [session, setSession] = useState(null);
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [isLoggingIn, setIsLoggingIn] = useState(false);
  const handleLogin = async () => {
    if (!supabaseAnonKey.startsWith('sb_publishable_')) {
      setSubmitResult({success:false,message:'Gunakan publishable key sb_publishable_, bukan secret/service_role key.'}); return;
    }
    setIsLoggingIn(true);
    try {
      const response = await fetch(`${supabaseUrl}/auth/v1/token?grant_type=password`, {
        method:'POST',headers:{apikey:supabaseAnonKey,'Content-Type':'application/json'},
        body:JSON.stringify({email,password})
      });
      const data=await response.json();
      if(!response.ok)throw new Error(data.error_description || data.msg || data.message || 'Login gagal');
      const accountsResponse=await fetch(`${supabaseUrl}/rest/v1/chart_of_accounts?select=*&order=account_code`, {
        headers:{apikey:supabaseAnonKey,Authorization:`Bearer ${data.access_token}`}
      });
      const accounts=await accountsResponse.json();
      if(!accountsResponse.ok)throw new Error(accounts.message || 'Gagal membaca akun');
      setAccounts(accounts.map(a=>({id:String(a.account_id),name:a.account_name,is_cash:a.is_cash})));
      setSession(data);setPassword('');
      setLines(current=>current.map((line,i)=>({...line,account_id:String(accounts.find(a=>a.account_code===(i===0?'5201':'1102'))?.account_id || '')})));
      setSubmitResult({success:true,message:'Login berhasil dan akun master dimuat.'});setShowConfig(false);
    } catch(err) {setSubmitResult({success:false,message:err.message});}
    finally {setIsLoggingIn(false);}
  };
  const logout = async () => {
    const token=session?.access_token;
    setSession(null);setAccounts([]);setPassword('');setShowConfig(true);
    setLines(current=>current.map(line=>({...line,account_id:''})));
    try {
      if(token){const response=await fetch(`${supabaseUrl}/auth/v1/logout`,{method:'POST',headers:{apikey:supabaseAnonKey,Authorization:`Bearer ${token}`}});
      if(!response.ok)throw new Error('Sesi lokal ditutup, tetapi pencabutan sesi server gagal.');}
      setSubmitResult({success:true,message:'Keluar dari aplikasi.'});
    } catch(err){setSubmitResult({success:false,message:err.message});}
  };

  const totals = useMemo(() => journalTotals(lines), [lines]);
  const validation = useMemo(() => validateVoucher(lines, MASTER_ACCOUNTS,
    {date,reference,description}), [lines,MASTER_ACCOUNTS,date,reference,description]);

  const addRow = () => {
    if(lines.length>=100)return;
    setLines([...lines, { id: crypto.randomUUID(), account_id: '', debit: '0', credit: '0' }]);
  };

  const removeRow = (id) => {
    if (lines.length <= 2) return; // Keep minimum 2 rows
    setLines(lines.filter(l => l.id !== id));
  };

  const updateLine = (id, field, value) => {
    setLines(lines.map(line => {
      if (line.id !== id) return line;
      const updated = { ...line, [field]: value };
      // Mutual exclusivity helper for UX convenience: if entering debit, clear credit and vice-versa
      if (field === 'debit' && (parseToCents(value) ?? 0n) > 0n) {
        updated.credit = '0';
      } else if (field === 'credit' && (parseToCents(value) ?? 0n) > 0n) {
        updated.debit = '0';
      }
      return updated;
    }));
  };

  const handleSubmit = async (e) => {
    e.preventDefault();
    if (!validation.isValid || !session || isSubmitting) return;

    if (!supabaseUrl || !supabaseAnonKey) {
      setShowConfig(true);
      setSubmitResult({ 
        success: false, 
        message: 'Harap masukkan Supabase URL dan Publishable Key terlebih dahulu pada panel konfigurasi.' 
      });
      return;
    }

    setIsSubmitting(true);
    setSubmitResult(null);

    try {
      /* Formatting payload as decimal string for RPC */
      const p_lines = lines.map(l => ({
        account_id: l.account_id,
        debit: decimalString(l.debit),
        credit: decimalString(l.credit)
      }));

      const response = await fetch(`${supabaseUrl}/rest/v1/rpc/submit_cash_voucher`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'apikey': supabaseAnonKey,
          'Authorization': `Bearer ${session.access_token}`
        },
        body: JSON.stringify({
          p_date: date,
          p_reference: reference,
          p_description: description,
          p_lines: p_lines
        })
      });

      if (!response.ok) {
        const errData = await response.json().catch(() => ({}));
        throw new Error(errData.message || `Gagal mengirim ke server (HTTP ${response.status})`);
      }

      const id=await response.json();
      setReference('');
      setSubmitResult({success:true,message:`Voucher #${id} berhasil diposting via RPC Supabase.`});
    } catch (err) {
      setSubmitResult({
        success: false,
        message: `Error koneksi / RPC: ${err.message}. Pastikan fungsi RPC 'submit_cash_voucher' sudah dibuat di database Anda.`
      });
    } finally {
      setIsSubmitting(false);
    }
  };

  return (
    <div className="min-h-screen bg-emerald-50/50 text-slate-800 pb-16 font-sans">
      {/* Header Banner */}
      <header className="bg-emerald-700 text-white shadow-md py-6 px-4 md:px-8">
        <div className="max-w-5xl mx-auto flex flex-col md:flex-row justify-between items-start md:items-center gap-4">
          <div>
            <div className="flex items-center gap-2">
              <FileText className="w-8 h-8 text-emerald-200" />
              <h1 className="text-2xl font-bold tracking-tight">Voucher Kas Keluar</h1>
            </div>
            <p className="text-emerald-100 text-sm mt-1">Sistem Akuntansi Keuangan Presisi Sen (Integer-based)</p>
          </div>
          <button 
            onClick={() => setShowConfig(!showConfig)}
            className="bg-emerald-800 hover:bg-emerald-900 text-emerald-100 text-xs px-3 py-2 rounded-lg border border-emerald-600 flex items-center gap-1.5 transition"
          >
            <Database className="w-4 h-4" />
            {showConfig ? 'Tutup Konfigurasi Supabase' : 'Konfigurasi Supabase RPC'}
          </button>
        </div>
      </header>

      <main className="max-w-5xl mx-auto px-4 md:px-8 mt-8">
        
        {/* Supabase Configuration Drawer */}
        {showConfig && (
          <div className="bg-white border border-emerald-200 shadow-lg rounded-xl p-6 mb-8 transition-all">
            <h3 className="font-semibold text-emerald-900 flex items-center gap-2 mb-2">
              <Database className="w-5 h-5 text-emerald-600" />
              Pengaturan Koneksi Supabase RPC
            </h3>
            <p className="text-xs text-slate-600 mb-4">
              Masukkan URL proyek Supabase dan Publishable Key Anda untuk mengaktifkan pengiriman data ke fungsi database <code className="bg-slate-100 px-1 py-0.5 rounded text-emerald-700 font-mono">submit_cash_voucher</code>.
            </p>
            <div className="grid grid-cols-1 md:grid-cols-2 gap-4">
              <div>
                <label className="block text-xs font-medium text-slate-700 mb-1">Supabase URL</label>
                <input 
                  type="text" 
                  placeholder="https://xxxx.supabase.co" 
                  value={supabaseUrl}
                  readOnly
                  className="w-full text-sm border border-slate-300 rounded-lg px-3 py-2 focus:ring-2 focus:ring-emerald-500 focus:outline-none"
                />
              </div>
              <div>
                <label className="block text-xs font-medium text-slate-700 mb-1">Supabase Publishable Key</label>
                <input 
                  type="password" 
                  placeholder="sb_publishable_..." 
                  value={supabaseAnonKey}
                  disabled={Boolean(session)}
                  onChange={(e) => setSupabaseAnonKey(e.target.value)}
                  className="w-full text-sm border border-slate-300 rounded-lg px-3 py-2 focus:ring-2 focus:ring-emerald-500 focus:outline-none"
                />
              </div>
            </div>
            {!session ? <div className="grid gap-3 mt-4">
              <p className="text-sm">Masuk memakai pengguna Supabase Auth aplikasi, bukan akun dashboard. Sesi hanya disimpan dalam memori halaman.</p>
              <label>Email<input type="email" autoComplete="username" value={email} onChange={e=>setEmail(e.target.value)} className="w-full border rounded p-2" /></label>
              <label>Password<input type="password" autoComplete="current-password" value={password} onChange={e=>setPassword(e.target.value)} className="w-full border rounded p-2" /></label>
              <button type="button" disabled={isLoggingIn || !email || !password || !supabaseAnonKey} onClick={handleLogin} className="bg-emerald-700 text-white rounded p-2 disabled:opacity-50">{isLoggingIn?'Memproses...':'Masuk'}</button>
            </div> : <div className="mt-4"><p>{session.user.email}</p><button type="button" onClick={logout} className="border rounded p-2">Keluar</button></div>}

        )}

        {/* Notification Banner */}
        {submitResult && (

import {cents,displayMoney} from '../frontend/money.mjs';

export function decimalString(value){
 const amount=cents(value);
 if(amount===null)throw new Error('Nominal tidak valid');
 return (amount/100n).toString()+'.'+(amount%100n).toString().padStart(2,'0');
}
export function journalTotals(lines){
 let debit=0n,credit=0n,valid=true;
 for(const line of lines){
   const d=cents(line.debit),c=cents(line.credit);
   if(d===null||c===null){valid=false;continue;}
   debit+=d;credit+=c;
 }
 return {debit,credit,balanced:valid&&debit>0n&&debit===credit};
}
export function validateVoucher(lines,accounts,metadata){
 const errors=[];let cashCount=0;
 if(lines.length<2||lines.length>100)errors.push('Jumlah baris harus 2–100.');
 if(!metadata.date||!metadata.reference.trim()||!metadata.description.trim())errors.push('Tanggal, nomor bukti, dan deskripsi wajib diisi.');
 if(metadata.reference.length>50)errors.push('Nomor bukti maksimal 50 karakter.');
 for(const line of lines){
   const a=accounts.find(a=>a.id===line.account_id);
   const d=cents(line.debit),c=cents(line.credit);
   if(!a){errors.push('Pilih akun master yang valid.');continue;}
   if(d===null||c===null){errors.push('Nominal harus rupiah positif/nol dengan maksimal dua desimal, tanpa pemisah ribuan.');continue;}
   if(!((d>0n&&c===0n)||(c>0n&&d===0n)))errors.push('Setiap baris harus memiliki tepat satu nominal positif.');
   if(a.is_cash){cashCount++;if(!(d===0n&&c>0n))errors.push('Akun Kas/Bank wajib di kredit untuk voucher kas keluar.');}
   else if(!(d>0n&&c===0n))errors.push('Seluruh akun lawan wajib di debit.');
 }
 if(cashCount!==1)errors.push('Wajib tepat satu baris Kas/Bank.');
 if(!journalTotals(lines).balanced)errors.push('Total debit harus sama dengan kredit dan lebih dari nol.');
 return {isValid:errors.length===0,errors:[...new Set(errors)]};
}

export function cents(value) {
  if (!/^\d{1,16}(\.\d{1,2})?$/.test(String(value))) return null;
  const [whole, fraction=''] = String(value).split('.');
  return BigInt(whole)*100n+BigInt(fraction.padEnd(2,'0'));
}
export function totals(lines) {
  let debit=0n,credit=0n;
  for (const line of lines) {
    const d=cents(line.debit),c=cents(line.credit);
    if(d===null||c===null||!line.account_id||!((d>0n&&c===0n)||(c>0n&&d===0n))) return {valid:false,debit,credit};
    debit+=d;credit+=c;
  }
  return {valid:lines.length>=2&&lines.length<=100&&debit>0n&&debit===credit,debit,credit};
}
export function displayMoney(value) {
  return 'Rp '+(value/100n).toString().replace(/\B(?=(\d{3})+(?!\d))/g,'.')+','+(value%100n).toString().padStart(2,'0');
}

-- Pengamanan tambahan konteks Soal 1; akan dilengkapi audit log pada Soal 3.
BEGIN;
CREATE FUNCTION public.guard_journal_header() RETURNS trigger
LANGUAGE plpgsql SET search_path = pg_catalog, public AS $$
DECLARE n BIGINT; d NUMERIC; c NUMERIC;
BEGIN
    IF TG_OP <> 'INSERT' AND OLD.status_posting = 'POSTED' THEN
        RAISE EXCEPTION 'Jurnal POSTED tidak boleh diubah atau dihapus; gunakan jurnal pembalik';
    END IF;
    IF TG_OP = 'DELETE' THEN RETURN OLD; END IF;
    IF TG_OP = 'INSERT' AND NEW.status_posting <> 'DRAFT' THEN
        RAISE EXCEPTION 'Jurnal baru wajib berstatus DRAFT';
    END IF;
    IF TG_OP = 'UPDATE' AND NEW.id <> OLD.id THEN
        RAISE EXCEPTION 'ID jurnal tidak boleh diubah';
    END IF;
    IF NEW.status_posting = 'POSTED' THEN
        SELECT count(*), coalesce(sum(debit),0), coalesce(sum(credit),0)
        INTO n,d,c FROM public.journal_lines WHERE header_id = NEW.id;
        IF n < 2 OR d <= 0 OR d <> c THEN
            RAISE EXCEPTION 'Posting ditolak: minimal dua baris dan total debit = kredit > 0';
        END IF;
    END IF;
    RETURN NEW;
END $$;
CREATE TRIGGER guard_journal_header BEFORE INSERT OR UPDATE OR DELETE
ON public.journal_headers FOR EACH ROW EXECUTE FUNCTION public.guard_journal_header();

CREATE FUNCTION public.guard_journal_line() RETURNS trigger
LANGUAGE plpgsql SET search_path = pg_catalog, public AS $$
DECLARE target_id BIGINT; s TEXT;
BEGIN
    IF TG_OP = 'UPDATE' AND NEW.header_id <> OLD.header_id THEN
        RAISE EXCEPTION 'Baris tidak boleh dipindahkan ke header lain';
    END IF;
    IF TG_OP = 'DELETE' THEN target_id := OLD.header_id;
    ELSE target_id := NEW.header_id; END IF;
    -- Semua perubahan baris menggunakan lock header yang sama dengan posting.
    SELECT status_posting INTO s FROM public.journal_headers
        WHERE id = target_id FOR UPDATE;
    IF NOT FOUND THEN RAISE EXCEPTION 'Header jurnal tidak ditemukan'; END IF;
    IF s <> 'DRAFT' THEN RAISE EXCEPTION 'Baris jurnal POSTED tidak boleh diubah'; END IF;
    IF TG_OP = 'DELETE' THEN RETURN OLD; END IF;
    RETURN NEW;
END $$;
CREATE TRIGGER guard_journal_line BEFORE INSERT OR UPDATE OR DELETE
ON public.journal_lines FOR EACH ROW EXECUTE FUNCTION public.guard_journal_line();
REVOKE EXECUTE ON FUNCTION public.guard_journal_header(),public.guard_journal_line() FROM PUBLIC;
COMMIT;

CREATE FUNCTION private.journal_digest(h public.journal_headers) RETURNS TEXT
LANGUAGE sql STABLE SET search_path = '' AS $$
 SELECT encode(extensions.digest(convert_to(jsonb_build_object(
   'version',1,'id',h.id,'date',h.transaction_date,'reference',h.reference_no,
   'description',h.description,'status',h.status_posting,'created_by',h.created_by,
   'created_at_epoch',extract(epoch FROM h.created_at),'reversal_of',h.reversal_of,
   'lines',(SELECT coalesce(jsonb_agg(jsonb_build_object('id',l.id,'account',l.account_id,
     'debit',l.debit,'credit',l.credit) ORDER BY l.id),'[]'::jsonb)
     FROM public.journal_lines l WHERE l.header_id=h.id)
 )::text,'UTF8'),'sha256'),'hex');
$$;
-- Trigger menghitung checksum, bukan menerima checksum dari frontend.
CREATE FUNCTION private.stamp_journal() RETURNS trigger
LANGUAGE plpgsql SET search_path = '' AS $$
BEGIN
 IF TG_OP='INSERT' THEN
   NEW.created_by := auth.uid(); NEW.created_at := clock_timestamp(); NEW.hash_checksum := NULL;
   IF NEW.reversal_of IS NOT NULL THEN
     IF NOT EXISTS(SELECT 1 FROM public.journal_headers WHERE id=NEW.reversal_of
       AND status_posting='POSTED' AND created_by=auth.uid()) THEN
       RAISE EXCEPTION 'Jurnal asal pembalik tidak valid';
     END IF;
   END IF;
 ELSE
   IF NEW.created_by IS DISTINCT FROM OLD.created_by OR NEW.created_at IS DISTINCT FROM OLD.created_at
     OR NEW.reversal_of IS DISTINCT FROM OLD.reversal_of THEN
     RAISE EXCEPTION 'Metadata pembuat dan referensi pembalik tidak boleh diubah';
   END IF;
   IF NEW.status_posting='POSTED' AND OLD.status_posting='DRAFT' THEN
     NEW.hash_checksum := private.journal_digest(NEW);
   ELSE NEW.hash_checksum := OLD.hash_checksum; END IF;
 END IF;
 RETURN NEW;
END $$;
CREATE TRIGGER a_stamp_journal BEFORE INSERT OR UPDATE ON public.journal_headers

CREATE FUNCTION public.submit_cash_voucher(p_date DATE,p_reference TEXT,p_description TEXT,p_lines JSONB)
RETURNS BIGINT LANGUAGE plpgsql SECURITY INVOKER SET search_path = '' AS $$
DECLARE h BIGINT; r JSONB; cash_count INT:=0; a public.chart_of_accounts; d NUMERIC; c NUMERIC;
BEGIN
 IF auth.uid() IS NULL THEN RAISE EXCEPTION 'Login diperlukan'; END IF;
 IF jsonb_typeof(p_lines) IS DISTINCT FROM 'array' THEN RAISE EXCEPTION 'Baris wajib array'; END IF;
 IF jsonb_array_length(p_lines)<2 OR jsonb_array_length(p_lines)>100 THEN RAISE EXCEPTION 'Jumlah baris harus 2-100'; END IF;
 INSERT INTO public.journal_headers(transaction_date,reference_no,description)
 VALUES(p_date,p_reference,p_description) RETURNING id INTO h;
 FOR r IN SELECT value FROM jsonb_array_elements(p_lines) LOOP
   d:=(r->>'debit')::numeric; c:=(r->>'credit')::numeric;
   IF d IS NULL OR c IS NULL OR d<>round(d,2) OR c<>round(c,2) THEN RAISE EXCEPTION 'Nominal wajib maksimal dua desimal'; END IF;
   SELECT * INTO a FROM public.chart_of_accounts WHERE account_id=(r->>'account_id')::bigint;
   IF NOT FOUND THEN RAISE EXCEPTION 'Akun tidak ditemukan'; END IF;
   IF a.is_cash THEN
     IF c<=0 OR d<>0 THEN RAISE EXCEPTION 'Kas keluar harus di sisi kredit'; END IF;
     cash_count:=cash_count+1;
   ELSIF d<=0 OR c<>0 THEN RAISE EXCEPTION 'Akun lawan harus di sisi debit'; END IF;
   INSERT INTO public.journal_lines(header_id,account_id,debit,credit) VALUES(h,a.account_id,d,c);
 END LOOP;
 IF cash_count<>1 THEN RAISE EXCEPTION 'Voucher harus memiliki tepat satu baris kas kredit'; END IF;
 UPDATE public.journal_headers SET status_posting='POSTED' WHERE id=h;
 RETURN h;
END $$;

CREATE FUNCTION public.reverse_journal(p_original BIGINT,p_date DATE,p_reference TEXT,p_reason TEXT)
RETURNS BIGINT LANGUAGE plpgsql SECURITY INVOKER SET search_path = '' AS $$
DECLARE h BIGINT; old_h public.journal_headers;
BEGIN
 IF auth.uid() IS NULL THEN RAISE EXCEPTION 'Login diperlukan'; END IF;
 SELECT * INTO old_h FROM public.journal_headers WHERE id=p_original AND status_posting='POSTED';
 IF NOT FOUND THEN RAISE EXCEPTION 'Jurnal POSTED milik pengguna tidak ditemukan'; END IF;
 INSERT INTO public.journal_headers(transaction_date,reference_no,description,reversal_of)
 VALUES(p_date,p_reference,p_reason,p_original) RETURNING id INTO h;
 INSERT INTO public.journal_lines(header_id,account_id,debit,credit)
 SELECT h,account_id,credit,debit FROM public.journal_lines WHERE header_id=p_original ORDER BY id;
 UPDATE public.journal_headers SET status_posting='POSTED' WHERE id=h;
 RETURN h;
END $$;
CREATE FUNCTION public.verify_journal(p_id BIGINT) RETURNS BOOLEAN
LANGUAGE sql SECURITY INVOKER STABLE SET search_path = '' AS $$
 SELECT h.hash_checksum=private.journal_digest(h) FROM public.journal_headers h
 WHERE h.id=p_id AND h.status_posting='POSTED';
